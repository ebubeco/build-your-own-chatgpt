📋 All Ollama Commands

ollama pull
Download a model from the Ollama library
ollama pull qwen2.5:7b
ollama run
Start a chat session with a model directly in terminal
ollama run qwen2.5:7b
ollama list
Show all installed models
ollama list
ollama show
Display model details (parameters, size, modified date)
ollama show qwen2.5:7b
ollama create
Create a custom model from a Modelfile
ollama create my-model -f Modelfile
ollama cp
Copy a model to create a new variant
ollama cp qwen2.5:7b my-custom-qwen
ollama rm
Delete a model from your system
ollama rm qwen2.5:7b
ollama serve
Start the Ollama server (API available at localhost:11434)
ollama serve
ollama ps
Show currently running models
ollama ps
ollama stop
Stop a running model
ollama stop qwen2.5:7b

⚙️ Modelfile Reference

Basic Modelfile Structure
Create a custom model with system prompt and parameters
FROM qwen2.5:7b
SYSTEM "You are a helpful coding assistant."
PARAMETER temperature 0.7
PARAMETER num_ctx 4096
PARAMETER top_p 0.9
Common Parameters
Most useful parameters to customize model behavior
temperature 0.7      # Creativity (0=exact, 1=creative)
num_ctx 4096        # Context window size
top_p 0.9           # Nucleus sampling threshold
top_k 40            # Consider top K tokens
repeat_penalty 1.1  # Penalize repetition
stop []             # Stop sequences (comma-separated)
Quantization Options
Reduce model size with minimal quality loss
ollama create my-model:q4 -f Modelfile

Then pull the base model and run: ollama create my-model:q4 -f Modelfile qwen2.5:7b-q4_K_M

🌐 API Reference

Generate Endpoint (curl)
Basic text generation via the Ollama API
curl http://localhost:11434/api/generate \
  -d '{"model":"qwen2.5:7b","prompt":"Hello","stream":false}'
Chat Endpoint (curl)
Conversation-style API with message history
curl http://localhost:11434/api/chat \
  -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"Hello"}]}'
OpenAI-Compatible Endpoint
Use Ollama with any OpenAI SDK-compatible tool
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"Hello"}]}'
Set base URL to http://localhost:11434/v1 when using OpenAI SDK with Ollama.

🐳 Docker / OpenWebUI

Start OpenWebUI
Full-featured chat interface (requires Docker)
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  ghcr.io/open-webui/open-webui:main

Then open http://localhost:3000 in your browser.

Ollama + OpenWebUI (docker-compose)
Run both Ollama and OpenWebUI together
services:
  ollama:
    image: ollama/ollama:latest
    volumes:
      - ollama:/root/.ollama
    ports:
      - "11434:11434"
  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    ports:
      - "3000:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
    depends_on:
      - ollama
