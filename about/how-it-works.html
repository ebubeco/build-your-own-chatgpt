How Local AI Works

Local AI runs a large language model directly on your hardware. Here's what happens under the hood when you send a prompt — and why running locally is faster, cheaper, and more private than the cloud.

Inference: The Core Process

When you type a message and press enter, here's the step-by-step process:

  1. Tokenization: Your prompt is split into tokens (words/subwords). A model like Qwen 2.5 7B uses ~30K tokens for a typical paragraph.
  2. Forward Pass: Each token passes through the model's neural network layers. The model computes probabilities for the next token.
  3. Sampling: The next token is selected based on probability (with temperature controlling randomness).
  4. Autoregressive Loop: Steps 2-3 repeat, feeding each new token back in, until the model produces a stop token or the max length is reached.

Hardware Acceleration

  • CUDA (NVIDIA): Ollama uses NVIDIA GPUs via CUDA for fast inference. RTX 3060 12GB runs 7B models at ~30 tokens/second.
  • Metal (Apple): Apple Silicon uses Metal Performance Shaders. M3 Max runs 14B models at ~20 tokens/second.
  • ROCm (AMD): AMD GPUs supported via ROCm. RX 7900 XTX runs 14B models at ~25 tokens/second.
  • CPU Inference: No GPU? Ollama falls back to CPU using optimized BLAS libraries. Slower but works on any computer.

Privacy & Security

  • 100% Local: Your data never leaves your machine. No API calls, no cloud processing, no data logs.
  • Offline: After the initial model download, no internet connection is required.
  • No Account: No sign-up, no subscription, no credit card. Download Ollama and pull a model — that's it.
