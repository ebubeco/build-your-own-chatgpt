What is a Local AI Model?

A local AI model is a large language model (LLM) that runs entirely on your computer — no internet, no subscription, no data leaving your machine.

How LLMs Work

Large language models are neural networks trained on vast amounts of text. They predict the next word in a sequence, which lets them generate human-like responses, write code, answer questions, and more. When you run a model locally with Ollama, it downloads the model weights (typically 2-40GB) and runs inference using your computer's CPU, GPU, or both.

Key Concepts

  • Model Size: Measured in parameters (e.g., 7B = 7 billion). More parameters = smarter but slower and needs more RAM/VRAM.
  • Quantization: Compresses the model to use less memory while maintaining quality. Q4_K_M is the recommended default.
  • Context Window: How many tokens (words/characters) the model can remember. Longer = better for conversations and large documents.
  • VRAM vs RAM: GPU memory (VRAM) is fastest. CPU RAM works too but is slower. Apple Silicon unifies both.

Choosing a Model

  • No GPU / 8GB RAM: Phi-4-mini (3.8B), Llama 3.2 (1B/3B), Qwen 2.5 (1.5B)
  • 4-8GB VRAM / 16GB RAM: Qwen 2.5 (7B), Gemma 3 (9B), Mistral (7B)
  • 8-16GB VRAM / 32GB RAM: Qwen 2.5 (14B), Phi-4 (14B), DeepSeek R1 (8B)
  • 24GB+ VRAM / 64GB+ RAM: Qwen 2.5 (32B), DeepSeek R1 (32B), Qwen 3 (35B)
