Groq
Fastest free AI
1,000+ tokens/sec. No credit card. Best for real-time chat.
1Go to console.groq.com → click "Sign Up" → use Google or email
2Go to console.groq.com/keys → click "Create API Key" → copy it
3Create a file named Modelfile with this content:
FROM openai/chat BASE_URL https://api.groq.com/openai/v1 API_KEY gsk_your_key_here
4Run these commands in your terminal:
ollama create groq-llama -f Modelfile ollama run groq-llama
5That's it. Chat with Llama 3.1 8B at ~1,000 tokens per second.

Cerebras - Python example
Fastest free inference (~3,000 tok/s)
from openai import OpenAI client = OpenAI( api_key="csk_your_key_here", base_url="https://api.cerebras.ai/openai/v1" ) response = client.chat.completions.create( model="llama3.1-8b", # or "gpt-oss-120b" for max speed messages=[{"role": "user", "content": "Hello!"}], max_tokens=1024 ) print(response.choices[0].message.content)
Fireworks AI - Python example
JSON schema mode (only free platform)
from openai import OpenAI import json client = OpenAI( api_key="fw_your_key_here", base_url="https://api.fireworks.ai/inference/v1" ) response = client.chat.completions.create( model="accounts/fireworks/models/kimi-k2-5", messages=[ {"role": "system", "content": "Extract structured data. Return only valid JSON."}, {"role": "user", "content": "Extract the name and email from: 'Hi I'm Jo, jo@example.com'"} ], response_format={"type": "json_object"}, max_tokens=512 ) data = json.loads(response.choices[0].message.content) print(data) # {"name": "Jo", "email": "jo@example.com"}

Groq Whisper - Speech to text
Only free STT (300 TPS, 2,000 req/day)
from groq import Groq client = Groq(api_key="gsk_your_key_here") with open("audio.mp3", "rb") as f: transcription = client.audio.transcriptions.create( file=("audio.mp3", f.read()), model="whisper-large-v3-turbo", response_format="text", language="en" ) print(transcription)
Groq Compound Beta - Batch processing
70,000 TPM — full backlog in one pass
from groq import Groq client = Groq(api_key="gsk_your_key_here") transcripts = ["transcript 1...", "transcript 2...", "transcript 3..."] results = [] for transcript in transcripts: response = client.chat.completions.create( model="compound-beta", messages=[ {"role": "system", "content": "Write concise show notes from this transcript."}, {"role": "user", "content": transcript} ] ) results.append(response.choices[0].message.content) print(results)
