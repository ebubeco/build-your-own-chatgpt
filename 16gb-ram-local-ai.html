Frequently Asked Questions

Can I run 7B models on 16GB RAM?

Yes, on CPU. It will be slower than GPU but functional for most tasks.

Do I need a GPU for Ollama?

No. Ollama runs on CPU too. Performance is slower but works for async tasks.

Is 16GB RAM enough for local AI?

Enough for 3B-7B models. For real-time chat, an NVIDIA GPU or Apple Silicon is recommended.

What speed should I expect on CPU?

3-10 tokens per second for 7B models on modern CPUs. Adequate for reading, slow for conversation.
