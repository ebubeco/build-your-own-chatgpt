The 8-Step Evaluation Workflow

Use this pipeline for consistent, high-quality annotation and evaluation. Each step uses a different platform optimized for that task.

1

Anchor + Instruction

Groq

Run the prompt through Groq Llama 3.1 8B Instant first (14,400 RPD). Fastest option for initial evaluation. Use for high-volume annotation where speed matters.

Best for: batch annotation, speed-priority evaluation, initial pass

2

Reality Check

OpenRouter

Switch to OpenRouter DeepSeek R1 for Chain-of-Thought reasoning. The visible reasoning trace helps you verify the model's logic step by step.

Best for: complex reasoning verification, logic checking, CoT analysis

3

Logic Check

Cerebras

Run through Cerebras GPT OSS 120B at ~3,000 TPS for maximum throughput on large models. Best for deep reasoning checks on complex evaluation tasks.

Best for: deep reasoning, high-throughput evaluation, large model analysis

4

Ambiguity Check

Google AI Studio

Use Gemini 2.5 Flash with search grounding enabled. The native search capability verifies facts and reduces hallucination risk in real time.

Best for: fact-checking, search grounding, reducing hallucination risk

5

Root Cause Analysis

OpenRouter

Return to DeepSeek R1 for root cause analysis when evaluations disagree. The visible reasoning chain helps identify exactly where models diverge.

Best for: disagreement resolution, root cause analysis, model comparison

6

The Call

Google AI Studio

Use Gemini 2.5 Pro (50 requests/day free) for the final difficult cases. Higher reasoning capability for edge cases where other models disagree.

Best for: tie-breaking, edge cases, final difficult evaluations

7

Write It

Fireworks AI

Use Fireworks AI Kimi K2.5 (256K context) for writing final evaluation reports. The long context window handles full conversation histories and detailed feedback.

Best for: writing final reports, long-context analysis, detailed feedback

8

Batch QC

Groq

Final quality check using Groq Compound (70K tokens per minute). High-throughput batch verification of all evaluations before submission.

Best for: batch quality control, final verification, high-throughput checking
