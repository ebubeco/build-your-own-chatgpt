Can My Laptop Run Local AI?

Short answer: yes — most laptops made after 2015 can run some form of local AI. Whether you have a MacBook, Windows laptop, or Chromebook, here's exactly what your hardware can handle and how to get started.

How to Check Your Specs

  • Windows: Open Task Manager (Ctrl+Shift+Esc) → Performance tab → check RAM and GPU
  • macOS: Click Apple icon → About This Mac → check Memory and Chip
  • Linux: Run free -h for RAM, lspci | grep VGA for GPU
  • Chromebook: Settings → About Chrome OS → Diagnostics → check RAM

Getting Started in 3 Steps

  1. Install Ollama — free from ollama.com/download. Works on Windows, macOS, and Linux.
  2. Pull a model — based on your RAM from the table above. Example: ollama pull qwen2.5:7b
  3. Start chatting — ollama run qwen2.5:7b. Type your messages at the >>> prompt.
Quick start (16GB RAM laptop)
ollama pull qwen2.5:7b && ollama run qwen2.5:7b

Frequently Asked Questions

Can my 10-year-old laptop run AI?

If it has 8GB+ RAM and a 64-bit processor (most Intel Core i5/i7 from 2015+ qualify), yes. You can run Phi-4 Mini 3.8B or SmolLM2 1.7B. Expect 1-5 tokens per second on CPU — slow but functional for basic chat and writing.

Can a Surface Pro run local AI?

Yes. Surface Pro 7+ and newer with 16GB RAM can run Qwen 2.5 7B at 3-5 tokens/second on CPU. Surface Pro X (ARM) has limited compatibility — check Ollama's ARM support first.

MacBook Air vs MacBook Pro for AI?

Both work well. The key factor is RAM: 8GB runs small models, 16GB runs 7B models well, 24GB+ runs 14B+ models. MacBook Pro has active cooling (fans) for sustained workloads. MacBook Air may throttle under extended heavy use but works fine for typical chat sessions.

Can I run AI on a tablet or iPad?

Not directly via Ollama. iPads and Android tablets cannot run Ollama natively. Your best option is a free cloud service like Gemini (gemini.google.com) or Groq (console.groq.com) — both work in the browser with zero installation.
